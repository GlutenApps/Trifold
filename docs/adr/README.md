# Architecture decision records

An architecture decision record (ADR) is a short file about one choice that refines or departs from [DESIGN.md](../DESIGN.md): the context, the decision, and its consequences. They are numbered in order, and a later ADR amends or supersedes an earlier one. Together they are the record of how the design got to where it is, while `DESIGN.md` describes the result. When a new decision changes a product-level choice, add its row to the decision log below and bring `DESIGN.md` in line.

## Decision log

Product-level decisions by area, as they were settled. Rationale is in the ADRs and in `DESIGN.md`.

| Area | Decision |
|---|---|
| Platform | Electron app for Windows and macOS from one codebase, platform-specific code limited to build, menu, title bar and the primary modifier key (ADR 0006). Web-tech UI (React + TypeScript). |
| Backend | None. Fully local. No accounts. |
| Storage | Files-first Library folder (JSON + media). SQLite is a rebuildable index only. |
| Rules edition | 2024 rules are native. 2014 content is "legacy", allowed per campaign, with light automatic conversion. |

| Players | Represented by PC cards (name, HP, AC, saves, passives, portrait…). No sheets. |
| Homebrew | New-from-scratch or Duplicate-then-edit for monsters, items, spells, feats, species, backgrounds, conditions and classes (ADR 0026). Subclasses later. Duplicate is a universal verb (encounters, scenes, NPCs, PC cards, playlists). |
| Presenter | Second Electron window on a chosen display. Scene tree of any depth. Tree click selects; Enter, double-click or ▶ sends (ADR 0004); hover shows a thumbnail; undo-last-scene hotkey. | Shared sources | Campaign › Shared sources lists what a campaign's players are given: imported sources (never their creatures), homebrew one record at a time, and the stat blocks of companions and held NPCs. Off until turned on; the SRD is never sent. Players get it at the table, read-only, in that campaign only. See ADR 0060. |
| Books and stars | Sources opens on Books: every book across the imported files, with search, filters and bulk actions. Starred books' copies answer first after homebrew; a book can be turned off. Files holds re-parse, warnings, Edit source and removal. The drag-to-order list is gone. See ADR 0061. |
| Collections | Group books into collections on the Books tab. A campaign that uses collections shows only their books; one that uses none shows every book. A collection can be shared with a campaign's players, from the Books tab or the campaign's Shared sources tab. See ADR 0062. |
| Duplicates | A record in more than one file or book shows one copy: the GM's choice for that record, then homebrew, a starred book, imported files, then the SRD. Settle one with Always use this copy on its page, or on Sources › Duplicates. See ADR 0063. |
| Player packs | A campaign's Shared sources tab exports a player pack for before the first session; players open it from Join a campaign. See ADR 0064. |
| Deleting books | Sources › Books deletes a book, or a selection, after a typed DELETE; Re-parse keeps it out and importing its file again brings it back. See ADR 0065. |
| Book filter | The compendium's Book filter picks a book, a collection, or the SRD, homebrew or shared content by name; Browse on the Books tab picks the book there. See ADR 0066. |
| Sharing books | Share a book with a campaign's players from its row on the Books tab, a selection's Share…, or the campaign's Shared sources tab (Share a book…). Files no longer has Edit source. See ADR 0067. |
| Characters | Library › Characters (player mode): New character makes an External character (numbers and a sheet link) or a Trifold character (the sheet here, numbers worked out); an External one can become a Trifold one. Export, import, typed DELETE. See ADR 0068. |
| Sheets | In a joined campaign, My characters links one of your characters and opens it on the Sheets tab, which shows the sheet with the table's HP and conditions, its sheet link and Edit. See ADR 0069. |
| PC sheet link | A PC card can hold the player's character sheet link (PC form › Basics); the party row's external-link button opens it as a web tab. See ADR 0070. |
| Sheet updates | A player's level-up reaches the GM as a sheet update in Player devices, listing what would change, with Accept and Dismiss; Accept sheet updates automatically skips the prompt. See ADR 0071. |
| New PC from player sheet | A player not on the picker asks the GM to add their linked character; Add PC in Player devices makes the card and hands it over. See ADR 0072. |
| Import from PDF | New character › Trifold character › Import from PDF reads a character sheet PDF exported from another app and previews it before Create character; Update from PDF… on a Trifold sheet replaces the sheet the same way. See ADR 0073. |
| Resources | A Trifold sheet's Resources section tracks spell slots spent, limited-use features, hit dice and Heroic Inspiration, with Short rest and Long rest; spending a hit die at the table sends its healing there. See ADR 0074. |
| Rolling from the sheet | On the Sheets tab, a save, skill, initiative, attack, damage or spell attack rolls when clicked, at the table or privately; an initiative roll is entered while the fight waits for it. See ADR 0075. |
| Version check | A player's Trifold that cannot play with the GM's says which one needs an update, in Join a campaign and on the strip; a different version that can play shows a note. See ADR 0076. |
| First-run choice | A new Library asks how it will be used: Game master gets the sample campaign; Player opens on Join a campaign. Settings › Appearance changes it. See ADR 0077. |
| Starting Trifold | Every launch opens on Library › Campaigns; opening a campaign restores its console as it was. A console that fails says so and logs why, and closing the loading window quits. See ADR 0079. |
| Character setup at the table | Holding a PC with no sheet, the player is asked for one above the map (Use a Library character, Build one, Import from PDF, Not now); holding nothing, they can bring one and ask the GM to add it. The linked sheet is shared with the GM's Trifold (`sheetShare`, up to 256 KiB) and kept on the PC card to read. See ADR 0078. |
| Character sheet layout | A sticky turn bar, four tiles, abilities pinned beside sub-tabs from 640 px, pips for resources, slots by spell level with Cast; only what can be pressed looks pressable. See ADR 0080. |
| Web tabs | The stage `+` menu adds a web tab: an address the DM typed, hosted in a sandboxed Electron webview in one persistent session, so a hosted document or sheet sits beside the console as a tab and reopens where it was left at the next launch. Library-wide list stored with the layouts; close parks, remove forgets; modifier hotkeys reach through the page; every tab has Open in system browser. See ADR 0011. |
